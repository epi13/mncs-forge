# Security policy

Report suspected vulnerabilities privately through GitHub Security Advisories for
`epi13/mncs-forge`. Do not include secrets or protected evidence in public issues.

The package version remains `0.1.0a2`; current `main` also contains post-release internal
consolidation work. Forge is experimental and not an isolation boundary. See [the security
model](docs/security.md) before relying on configured providers or evaluator workflows.
